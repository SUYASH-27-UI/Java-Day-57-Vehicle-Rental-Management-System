# Java Day 57 – Vehicle Rental Management System

## Description
A menu-driven Vehicle Rental Management System developed using Java. It manages vehicle rentals, customer records, rental charges and vehicle availability.

## Features
- Display available vehicles
- Rent a vehicle
- View all rental records
- Search rental by ID
- Return a rented vehicle
- Calculate rental charges
- Save records permanently

## Vehicle Rates
- Car: Rs. 1500/day
- Bike: Rs. 500/day
- SUV: Rs. 2500/day

## Technologies Used
- Java
- OOP
- ArrayList
- File Handling
- Exception Handling

## Files
- `Main.java` – Main Java program
- `rentals.txt` – Sample rental records

## How to Compile and Run

```bash
javac Main.java
java Main
```

## Concepts Learned
Classes, objects, ArrayList, file handling, searching, availability checking and calculations.
